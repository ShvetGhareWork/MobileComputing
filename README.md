# Mobile Computing Experiments

This repository contains the complete set of practical experiments for the Mobile Computing course (Academic Year 2025-2026).

## 📂 Project Structure

| Experiment | Title | Technology |
|---|---|---|
| [Ex 1](./Experiment%201%20-EMI%20Calculator/) | EMI Calculator | React Native (Expo) |
| [Ex 2](./Experiment%202%20-%20Frequency%20Reuse/) | Frequency Reuse Simulation | Python (Matplotlib) |
| [Ex 3](./Experiment%203%20-%20Canvas/SmartCanvas/) | SmartCanvas Drawing App | React Native (Expo) |
| [Ex 4](./Experiment%204%20-%20Bluetooth/BlueDrop/) | Bluetooth Connectivity | React Native (Expo) |
| [Ex 5](./Experiment%205%20-%20DBMS/TaskVault/) | Task Database (SQLite) | React Native (Expo) |
| [Ex 6](./Experiment%206%20-%20GPS/TrailMark/) | GPS Map Tracking | React Native (Expo) |
| [Ex 7](./Experiment%207%20-%20Alert%20Ping/PingBox/) | Background Services | React Native (Expo) |
| [Ex 8](./Experiment%208%20-%20CDMA/) | CDMA Simulation | Python (NumPy) |
| [Ex 9](./Experiment%209%20-%20SecMechanisms/) | GSM Authentication (SRES) | Python |
| [Ex 10](./Experiment%2010%20-%20GUI/ComponentKit/) | Advanced Component Kit | React Native (Expo) |

## 🚀 Setup & Installation

### For React Native (Experiments 1, 3, 4, 5, 6, 7, 10):
1. Install Node.js
2. Go to the project folder
3. Run `npm install`
4. Run `npx expo start`
5. Scan QR with your device (Expo Go app)

### For Python (Experiments 2, 8, 9):
1. Install Python 3
2. Install dependencies: `pip install numpy matplotlib`
3. Run the script: `python <filename>.py`
