# Experiment 5: SQLite Database Integration (TaskVault)

## Description
A Task/Note management application showing how to integrate `expo-sqlite` for persistent data storage. It features full CRUD operations (Create, Read, Update, Delete) locally on the device without requiring an internet connection.

## Features
- Interactive Add/Edit/Delete Task interface
- Persistent storage using SQLite
- Search and filter by category/priority
- Smooth animations for task transitions
